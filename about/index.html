About

Small tools, built properly, sold once

Quidova is a UK maker of small, tested digital tools: free calculators that run in your browser, and spreadsheets that keep the running record.

What we make

One file, one job

Every paid file here is one spreadsheet built around one awkward question — who owes who, what a job really paid, how to plan a week that doesn't fall apart when you miss a day. Not a course, not a subscription, not a 40-tab “system” you will never open twice.

Each one is priced once. There is no renewal, no expiry date and no yearly edition to wait for.

What we don't make

We deliberately keep the catalogue small. Four earlier spreadsheets were retired rather than listed, because each one turned out to be a grid with almost no arithmetic in it — and a grid is something you can draw yourself for free.

How a file gets made

Tested, not assumed

  1. Built around a check figure decided before any cell is filled in — the number the worked example must produce when you first open it.
  2. Recalculated by an engine that isn't Excel, every formula, so the numbers are checked rather than just the file opening.
  3. Emptied — every example row deleted — to make sure a blank file doesn't break.
  4. Opened in Microsoft Excel for Windows and in Google Sheets in a desktop browser. Those are the two places we test. Everywhere else, we say we haven't.
  5. Checked against its own page, so a number in the sales copy cannot drift from the number in the file.

Things we won't do

Claims

  • No testimonials, ratings, review counts or customer numbers — because we would have to invent them.
  • No “normally £99” anchor and no fake discount.
  • No claim that a file works somewhere we have not opened it.
  • No “lifetime updates” and no guarantee we cannot keep.

If a page here ever states a figure, it came from the file it describes.

Where to start

Free first, always

The two calculators on this site are complete answers to their questions, not teasers. If you only ever use those, that is a fine outcome.
