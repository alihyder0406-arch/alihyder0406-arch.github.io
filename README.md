# Quidova — site

Static site for Quidova: free browser calculators (who owes who, job profit per hour) and
documentation for three tested spreadsheets. Purchases happen on Payhip, not here.

- Built by `tools/build_site.py` in the project folder (plain HTML/CSS/JS, no build step on GitHub).
- Deployed by `tools/deploy_site.py` to GitHub Pages from the `main` branch root.
- Nothing typed into the calculators is stored or sent anywhere. The site sets no cookies.
